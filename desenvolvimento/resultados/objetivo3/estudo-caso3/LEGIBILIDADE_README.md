# legibilidade_pt.py — Ferramenta de Análise de Legibilidade em Português\n\n## Visão Geral\n\nO `legibilidade_pt.py` é um script Python que calcula **5 índices de legibilidade** para textos em português, avaliando a complexidade da linguagem e acessibilidade do conteúdo.\n\nÉ a ferramenta central do **ContasClaras-AI** para validar se relatórios, notas e documentos seguem os padrões de linguagem simples.\n\n---\n\n## O Que Ele Faz\n\n### Métricas Calculadas\n\nO script analisa um texto e gera 5 indicadores científicos:\n\n| Métrica | Sigla | O Que Mede | Faixa Ideal |\n|---------|-------|-----------|------------|\n| **Flesch Reading Ease** | FRE | Facilidade geral de leitura (0-100) | ≥ 60 (fácil) |\n| **Índice de Gulpease** | GP | Legibilidade específica para PT (0-100) | ≥ 60 (fácil) |\n| **Índice Gunning Fog** | Fog | Anos de escolaridade necessários | ≤ 12 (público geral) |\n| **Índice de Coleman-Liau** | CLI | Série escolar aproximada | Fundamental-Médio |\n| **Índice ARI** | ARI | Nível de educação estimado | Fundamental-Médio |\n\n### Contagens Suportadas\n\nAlém das métricas, o script também gera:\n- **Frases:** número total de sentenças\n- **Palavras:** contagem de termos únicos\n- **Letras:** apenas caracteres alfabéticos\n- **Caracteres não-brancos:** para cálculo do ARI\n- **Sílabas:** estimativa heurística (importante para Flesch e Fog)\n- **Palavras complexas:** termos com ≥3 sílabas\n\n---\n\n## Como Usar\n\n### Instalação\n\nNenhuma instalação adicional necessária! O script usa apenas bibliotecas padrão do Python 3.6+:\n- `argparse` — processamento de argumentos\n- `re` — expressões regulares\n- `dataclasses` — estruturas de dados\n- `typing` — hints de tipo\n\n### Linha de Comando\n\n#### 1. Analisar texto direto\n\n```bash\npython legibilidade_pt.py --texto \"Seu texto aqui...\"\n```\n\n**Exemplo:**\n```bash\npython legibilidade_pt.py --texto \"O TCU fiscaliza contas públicas.\"\n```\n\n#### 2. Analisar arquivo de texto\n\n```bash\npython legibilidade_pt.py --arquivo caminho/para/arquivo.txt\n```\n\n**Exemplo:**\n```bash\npython legibilidade_pt.py --arquivo relatorio.txt\n```\n\n#### 3. Com interpretações simplificadas\n\nAdicione a flag `--interpretar` para obter explicações em português:\n\n```bash\npython legibilidade_pt.py --texto \"Seu texto aqui...\" --interpretar\n```\n\n---\n\n## Exemplo de Saída\n\n### Comando\n```bash\npython legibilidade_pt.py --texto \"A prefeitura implementou procedimentos administrativos otimizados.\" --interpretar\n```\n\n### Saída\n```\n=== Métricas de Legibilidade (ajustadas) ===\nFrases: 1 | Palavras: 7 | Letras: 47 | Caracteres (não brancos): 53 | Sílabas (heur.): 17 | Palavras complexas (≥3 sílabas): 3\nFlesch Reading Ease: 35.42\nÍndice de Gulpease: 48.57\nÍndice Gunning Fog: 13.82\nÍndice de Coleman–Liau: 8.12\nÍndice ARI: 9.67\n\nReferenciais úteis (aproximados):\n- Flesch: ≥60 fácil; 30–60 médio; <30 difícil. (constante ajustada em 248.835)\n- Gulpease: ≥60 fácil; 40–60 médio; <40 difícil.\n- Fog: ≤12 público geral; 12–16 intermediário; >16 avançado.\n- Coleman–Liau e ARI ≈ séries/anos escolares (base EN; usar como aproximação).\n\nInterpretação resumida:\n- Flesch Reading Ease: médio (exige alguma familiaridade).\n- Índice de Gulpease: médio.\n- Índice Gunning Fog: intermediário/superior introdutório (12–16).\n- Índice de Coleman–Liau: Fundamental II (aprox.)\n- Índice ARI: Fundamental II (aprox.)\n```\n\n---\n\n## Interpretando os Resultados\n\n### Flesch Reading Ease (FRE)\n\n**Escala:** 0–100\n- **≥ 90:** Muito fácil (crianças de 5 anos)\n- **60–90:** Fácil (público geral)\n- **30–60:** Médio (educação formal necessária)\n- **< 30:** Difícil (especialistas)\n\n**Constante:** Ajustada para 248.835 (padrão para português)\n\n### Índice de Gulpease\n\n**Escala:** 0–100 (específico para português)\n- **≥ 60:** Fácil\n- **40–60:** Médio\n- **< 40:** Difícil\n\n### Índice Gunning Fog\n\n**Escala:** Anos de educação formal necessários\n- **≤ 12:** Público geral (até ensino médio completo)\n- **12–16:** Intermediário/Nível superior introdutório\n- **> 16:** Avançado (pós-graduação)\n\n**Recomendação TCU:** Textos devem ter Fog ≤ 12.\n\n### Coleman-Liau (CLI) e ARI\n\n**Escala:** Série/ano escolar aproximado\n- **< 6:** Fundamental I\n- **6–10:** Fundamental II\n- **10–13:** Ensino médio\n- **> 13:** Nível superior\n\n*Nota: Baseados em dados do inglês; usados como aproximação para português.*\n\n---\n\n## Características Técnicas\n\n### Processamento de Texto\n\n1. **Normalização:** Remove espaços duplicados, trata abreviações (Dr., Sr., etc.)\n2. **Tokenização:** Extrai palavras com suporte a acentos e hífens\n3. **Contagem silábica:** Heurística baseada em grupos vocálicos\n4. **Detecção de complexidade:** Palavras com ≥3 sílabas são consideradas complexas\n\n### Suporte a Linguagem\n\n✅ **Português (PT-BR e PT-PT):**\n- Acentos completos: á, é, í, ó, ú, â, ê, ô, ã, õ\n- Caracteres especiais: ç, cedilha\n- Hífens e apóstrofos em palavras compostas\n\n✅ **Inglês:**\n- Compatibilidade com textos mistos\n\n### Formulas Utilizadas\n\n#### Flesch Reading Ease (ajustado para PT)\n```\nFRE = 248.835 − 1.015×(Palavras/Frases) − 84.6×(Sílabas/Palavras)\n```\n\n#### Índice de Gulpease\n```\nGulpease = 89 + (300×Frases − 10×Letras) / Palavras\n```\n\n#### Índice Gunning Fog\n```\nFog = 0.49 × (Palavras/Frases) + 23.275 × (Palavras_Complexas/Palavras)\n```\n\n#### Coleman-Liau\n```\nCLI = 0.054×L100 − 0.21×S100 − 14\n(onde L100 = letras por 100 palavras; S100 = frases por 100 palavras)\n```\n\n#### ARI (Automated Readability Index)\n```\nARI = 4.6×(Caracteres/Palavras) + 0.44×(Palavras/Frases) − 20\n```\n\n---\n\n## Integração com ContasClaras-AI\n\n### No Contexto do GPT\n\nO ContasClaras-AI utiliza este script automaticamente quando:\n\n1. **Usuário solicita:** \"Avaliar legibilidade de um texto...\"\n2. **Assistente carrega:** Arquivo `legibilidade_pt.py`\n3. **Script executa:** Analisa o texto e gera 5 indicadores\n4. **Resultado:** Faixas + interpretação em PT-BR\n\n### Exemplo de Fluxo\n\n```\nUsuário:\n\"Avaliar a legibilidade deste texto: A implementação de procedimentos \nadministrativos otimizados consequencia em maximização de eficiência...\"\n        ↓\nContasClaras-AI importa legibilidade_pt.py\n        ↓\nScript analisa e retorna:\n  - Flesch: 35.42 (médio)\n  - Gulpease: 48.57 (médio)\n  - Fog: 13.82 (intermediário)\n  - CLI: 8.12 (Fundamental II)\n  - ARI: 9.67 (Fundamental II)\n        ↓\nInterpretação final: \"Média legibilidade — linguagem excessivamente técnica.\"\n```\n\n---\n\n## Limitações Conhecidas\n\n1. **Contagem de sílabas:** Heurística baseada em vogais; não é perfeita para português complexo\n2. **Acrônimos:** Palavras totalmente em MAIÚSCULA com ≤4 caracteres não são contadas como complexas\n3. **Abreviações:** O script trata abreviações comuns (Dr., Sr.) mas pode não cobrir todas\n4. **Nomes próprios:** Não diferencia nomes próprios de palavras comuns\n5. **Escalas CLI/ARI:** Baseadas em dados do inglês; usar como aproximação para português\n\n---\n\n## Exemplos Práticos\n\n### Exemplo 1: Texto Simples (Bom para TCU)\n\n```bash\npython legibilidade_pt.py --texto \"O TCU encontrou gastos sem autorização.
